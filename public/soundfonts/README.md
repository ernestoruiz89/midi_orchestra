# SoundFont assets

- `general_user-2.0.2.sf2` is the lossless desktop GeneralUser GS bank.
- `general_user-mobile.sf3` is the compressed GeneralUser GS bank bundled by
  [SpessaSynth](https://github.com/spessasus/SpessaSynth). It is used for the
  mobile performance profile and data-saver connections.

The GeneralUser GS usage terms are preserved in `GENERALUSER-LICENSE.txt`.
